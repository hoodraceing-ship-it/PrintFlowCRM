# Security Policy

## Reporting a vulnerability

Please do not publish API keys, access tokens, customer data, private server addresses, or reproducible credential material in a public issue.

For ordinary bugs that do not expose sensitive information, use GitHub Issues. For a security-sensitive report, contact the repository owner privately through GitHub before posting technical details publicly.

## Secrets

PrintFlow CRM may store optional service credentials for the current Windows user. Contributors must never commit real credentials or local application data to this repository.
